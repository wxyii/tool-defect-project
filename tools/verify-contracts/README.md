# 契约验证

`verify_contracts.py` 使用标准库离线验证 v1/v2 JSON Schema、合法/非法示例、
状态迁移、OpenAPI 写接口示例、AsyncAPI 投递语义和消费者登记。验证器遇到未实现的
模式关键字会失败，避免静默漏检。

`compatibility.py --major 1|2` 将指定主版本的契约表面与独立基线比较；删除端点、方法、必填字段、
响应码或枚举值均视为破坏性变更。只有明确发布新主版本时才可更新对应基线。

`verify_v2_scope.py` 全量扫描第二版契约和生成类型，并检查显式第二版消费者源码表面；取消清单命中、历史快照独立路由或写请求滥用都会失败。脚本内置负向自测，防止门禁退化为无操作成功。
