# 刀具缺陷推理可视化设计

## 1. 目标

双任务推理除继续输出分类结果、概率和原始二值掩码外，还应生成一张中文检测结果图。非专业人员应能直接看出：

- 当前刀具被判定为“合格”还是“不合格”；
- 模型认为缺陷位于什么位置；
- 分类置信度是多少；
- 当分类与分割结果矛盾或无法定位时，需要人工复核。

可视化只解释模型输出，不承诺标记位置一定是真实缺陷，也不允许凭分类结果虚构缺陷位置。

## 2. 推荐输出样式

每张输入图片生成一张独立的检测结果 PNG：

- 保留原始刀具图片作为背景；
- 将模型分割出的缺陷区域以半透明红色覆盖；
- 在主要缺陷区域外绘制醒目的红色轮廓和编号；
- 在图片顶部增加深色中文信息栏；
- 不合格使用红色状态标识，合格使用绿色状态标识；
- 最大边限制为 1600 像素，不放大较小图片。

信息栏固定使用以下中文：

- 分类为不合格且存在定位：
  `检测结果：不合格　分类置信度：XX.XX%　检测到 N 处疑似缺陷`
- 分类为合格且不存在定位：
  `检测结果：合格　分类置信度：XX.XX%　未检测到缺陷区域`
- 分类为不合格但掩码为空：
  `检测结果：不合格　分类置信度：XX.XX%　未能定位缺陷区域，请人工复核`
- 分类为合格但掩码非空：
  `检测结果：合格　分类置信度：XX.XX%　分类与定位结果不一致，请人工复核`

图片底部增加简短图例：

`红色区域和轮廓：模型识别的疑似缺陷位置`

“疑似缺陷”和“模型识别”用于避免把模型预测错误表达成已经人工确认的事实。

## 3. 文件与职责

### `src/tool_defect/inference/visualize.py`

只负责把原图、原始预测掩码和分类结果转换为检测结果图：

1. 使用支持中文路径的方式读取原图；
2. 在模型的 256×256 掩码上做连通区域分析；
3. 仅为显示目的过滤孤立噪点；
4. 将显示掩码缩放到结果图尺寸；
5. 绘制红色覆盖层、轮廓、编号、中文状态栏和图例；
6. 保存压缩后的 PNG。

原始二值掩码不在该模块中修改。

### `src/tool_defect/inference/predict.py`

继续负责模型推理和原始结果保存。双任务模式下：

1. 保存未经可视化处理的二值掩码；
2. 调用可视化模块生成结果图；
3. 在 `predictions.csv` 中记录结果图相对路径；
4. 单张可视化失败时抛出包含输入文件名的明确异常，不产生“推理成功”的假象。

分类模式不生成缺陷定位图，现有行为保持不变。

## 4. 准确性与显示噪声

- `masks/` 中的原始掩码是模型输出的直接离散化结果，始终保留。
- 结果图中的显示掩码允许去除极小的孤立连通区域，以减少单像素噪声。
- 噪声阈值在 256×256 模型坐标中计算，不受原始图像分辨率影响。
- 默认只过滤面积小于 12 个模型像素的连通区域。
- 若过滤后没有缺陷区域，但原始掩码存在像素，信息栏显示：
  `仅检测到低可信度微小区域，请人工复核`
- 不使用膨胀操作人为扩大缺陷；半透明覆盖、轮廓线和编号只增强可读性。

## 5. 中文显示

- 使用 Pillow 绘制中文，避免 OpenCV 内置字体无法显示中文的问题。
- Windows 默认优先使用微软雅黑字体 `C:\Windows\Fonts\msyh.ttc`。
- 若微软雅黑不可用，依次检查黑体等支持中文的系统字体。
- 若找不到中文字体，程序应给出明确错误，不输出乱码图片。
- 状态文本由固定映射生成，不直接拼接未经验证的模型输出名称。

## 6. 性能

- 原图读取后先按最大边 1600 像素等比例缩小，再进行覆盖和文字绘制。
- 连通区域分析在 256×256 掩码上完成。
- 每张图片只进行一次原图解码、一次图像缩放和一次结果编码。
- 不改变模型推理批次和神经网络计算过程。
- 继续使用逐图输出，避免批量处理时保存所有高分辨率图像到内存。

## 7. 输出结构

```text
outputs/<任务目录>/
├─ predictions.csv
├─ masks/
│  └─ 0000_100.png
└─ visualizations/
   └─ 0000_100_result.png
```

`predictions.csv` 保留现有字段，并用 `visualization_path` 指向结果图。

## 8. 异常处理

- 输入图片不存在或无法解码：明确报告输入路径。
- 掩码不是二维数组：拒绝生成结果图。
- 分类名称或置信度无效：拒绝生成结果图。
- 中文字体不存在：明确报告已检查的字体位置。
- 结果图编码失败：明确报告目标路径。
- 输出目录不存在时自动创建。

## 9. 测试与验收

先写失败测试，再修改实现。

单元测试覆盖：

- 缺陷区域能产生红色覆盖、轮廓和中文状态栏；
- 原始掩码不会被可视化过程原地修改；
- 小于阈值的孤立噪点不生成缺陷编号；
- 空掩码输出“未能定位”或“未检测到”的正确说明；
- 分类和分割结果不一致时输出人工复核提示；
- 超大原图的结果最大边不超过 1600 像素；
- 中文路径可以正常读写；
- 找不到中文字体时给出明确错误。

集成验收：

- 用户给出的 `100.png` 命令执行成功；
- 原始掩码、中文结果图和 CSV 同时生成；
- 结果图可以正常打开，文件大小显著低于当前约 30 MB；
- 分类推理行为不受影响；
- 原有推理、评估和训练冒烟测试全部通过。

## 10. 不在本次范围内

- 不重新训练模型；
- 不修改模型权重；
- 不改变评价指标；
- 不根据人工经验移动、补画或删除真实缺陷；
- 不把当前模型预测表述为人工确认结果。
