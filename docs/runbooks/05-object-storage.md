# 对象存储故障

严重级别：S1

## 影响确认

- 区分不可达、不可写、读取摘要不符、暂存未确认和容量故障；记录受影响桶与时间窗。
- 原图未通过头信息和摘要确认前不得标记已持久化，检测结果保持 `HOLD`。

## 只读检查

- 查看健康、容量、版本状态、暂存对象年龄、对象头和业务引用数量。
- 随机重算对象 SHA-256；只通过后端受控下载，不从浏览器列桶。

## 恢复步骤

1. 恢复服务、网络或容量，先验证签名请求和只读对象。
2. 重新确认暂存上传；摘要冲突转入哈希冲突手册，不覆盖已有对象。
3. 扫描暂存与孤儿，形成候选清单并对账业务引用。

## 升级路径

- 原图疑似丢失、摘要冲突或多个副本不一致时立即升级 S1 事件指挥和存储负责人。

## 恢复验证

- 随机图片重算摘要、对象数量与数据库引用一致、暂存年龄回落且签名地址不泄漏。
- 引用闭包不完整时继续 `HOLD`。

## 危险操作控制

- 所需权限：对象维护；操作原因：对象范围和问题指纹；二次确认：质量负责人；审计事件：`storage.object.reconciled`。
- 禁止覆盖不可变对象、共享长期凭据或清理仍被引用的对象。
