# 网络中断

严重级别：S2

## 影响确认

- 区分采集到中心、服务到队列、服务到对象存储和遥测出口；记录最后成功时间与积压量。
- 采集继续本地原子落盘，中心不可确认时不得把图片标为已同步；未知任务保持 `HOLD`。

## 只读检查

- 查看链路健康、证书有效期、域名解析、退避次数、最老离线图片和磁盘安全余量。
- 用追踪标识核对中断前最后一条采集、发件箱、队列与推理事件，不修改状态。

## 恢复步骤

1. 恢复网络、路由或证书信任，先验证只读健康和时间同步。
2. 允许有限退避自然恢复，不批量重置尝试计数。
3. 对账采集、本地队列、中心任务和对象数量，随后受控排空积压。

## 升级路径

- 离线时长超过本地容量预算或多工位同时中断时升级 S1；单一遥测出口异常按监控失明流程升级。

## 恢复验证

- 随机检查中断窗口内图片摘要，确认无丢失、无重复业务结果、积压归零且追踪连续。
- 恢复前置条件不完整时继续 `HOLD`。

## 危险操作控制

- 所需权限：网络运维；操作原因：事件编号与受影响链路；二次确认：值班负责人；审计事件：`network.route.restored`。
- 禁止关闭证书校验、绕过服务身份或清空离线队列。
