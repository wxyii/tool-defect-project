# 生产员工操作手册

## 角色边界与高风险控制

- 所需权限：`PRODUCTION_EMPLOYEE` 仅允许查看授权工位、创建本人手工批次、上传图片和提交三按钮反馈；不得复核他人批次、管理用户、管理样本、发布模型、回滚、提权或修改审计事实。
- 操作原因：重采、暂停工位和升级事件必须选择或填写原因。
- 二次确认：暂停产线、清理缓存或使用应急流程前由运维负责人以不同账号确认。
- 审计事件：登录、重采、暂停、升级和权限拒绝均记录主体、工位、原因与结果。

权限、设备或结果状态未知时停止操作并保持 `HOLD`，不得手工改成 PASS。

受众：生产员工。权限：查看授权范围、创建和查看本人批次、提交三按钮反馈、确认设备提示和发起授权重采。禁止：修改质量结论、管理用户、样本和模型，或访问数据集、训练运行入口。

## 1. 正常操作

### 1.1 登录

- 使用分配的本地账号和密码登录工位终端。
- 登录后确认右上角显示本工位编号、产线名称和当前班次。
- 密码不得告知他人。忘记密码必须联系系统管理员重置，不允许共享账号。

### 1.2 查看工位

- 登录后默认进入工位实时页，顶部状态栏显示：
  - 工位编号、产线名称和当前时间。
  - 中心连接状态（绿色：已连接，黄色：延迟偏高，红色：断开）。
  - 相机、PLC 和采集代理状态。
- 中间区域显示最近一次检测图像和处置结果。
- 下方显示检测流水记录表，按时间倒序。

### 1.3 查看检测结果

- 每条检测记录包含：刀具 ID、时间戳、自动判定、复核状态和最终处置。
- `PASS`（合格）：工具继续使用，无需操作。
- `FAIL`（不合格）：工具被标记，等待后续处理。
- `HOLD`（待定）：结果未决，需等待人工复核或技术恢复。
- 点击单条记录可查看详情，包括原始图像、热图和分割掩膜。

### 1.4 设备确认与重采

- 当系统提示"建议重采"时，检查刀具位置、光源和相机是否正常后点击"确认重采"。
- 重采后确认新记录出现且状态正常。
- 连续三次重采仍异常时停止操作并通知现场负责人。

## 2. 处理 HOLD 结果

### 2.1 理解 HOLD

HOLD 表示系统无法自动判定，可能原因：
- 图像质量异常（过曝、过暗、模糊、遮挡）。
- 模型置信度在 Unknown 区间。
- 技术故障（网络中断、磁盘满、推理超时）。
- 复核超时升级。

### 2.2 HOLD 时操作

1. 检查工位状态栏是否有设备告警。
2. 如有相机或光源告警，检查并清洁设备后确认重采。
3. 如无设备告警，HOLD 将进入人工复核队列，无需操作员额外操作。
4. HOLD 样本不得手动标记为 PASS 或 FAIL。

### 2.3 升级

- 同一工位连续 10 条 HOLD 时通知质量负责人。
- 设备故障持续 5 分钟以上通知现场运维负责人。
- 疑似刀具批量异常时立即通知质量负责人和产线主管。

## 3. 处理设备告警

### 3.1 磁盘空间告警

- 黄色：磁盘使用率超过 80%，正常操作，通知运维关注。
- 橙色：磁盘使用率超过 90%，系统可能暂停新采集，立即通知运维。
- 红色：磁盘使用率超过 95%，采集已暂停，等待运维处置。此时已触发的刀具仍会完成上传。

### 3.2 网络告警

- 连接黄色：延迟升高，检测正常进行但上传可能缓慢。
- 连接红色：与中心断开。本地检测继续进行，结果缓存在工控机。
- 网络恢复后系统自动补传，操作员无需干预。确认补传完成后列表无未同步标记。

### 3.3 相机告警

- 相机断开：采集停止，后续刀具可能未被检测。立即检查相机连接线缆和电源。
- 图像异常：触发频繁 HOLD，检查镜头是否有污渍、光源是否正常。
- 手动处理无效时通知设备维护人员。

## 4. 交班

### 4.1 交班前检查

- [ ] 工位连接状态正常。
- [ ] 无持续设备告警。
- [ ] 本班次所有刀具已完成检测且结果已显示。
- [ ] 无超时未处理的异常状态。
- [ ] 接班人员使用独立账号登录。

### 4.2 交班记录

- 记录交接时间、班次、本班异常事件摘要。
- 如本班有设备故障或 HOLD 升级事件，在交班记录中备注。
- 在系统中完成交班确认。

## 5. 禁止操作

下列操作明确禁止：

1. 不得修改自动判定结果或复核结论。
2. 不得删除任何检测记录、原始图像或掩膜数据。
3. 不得使用他人账号登录或共享登录凭据。
4. 不得安装或卸载工控机软件，不得修改系统配置。
5. 不得关闭或重启采集代理、数据库或任何后台服务。
6. 不得断开相机、PLC 或网络连接（检修除外且需提前通知）。
7. 不得将检测图像导出到外部存储或发送到工位以外。
8. 不得在工控机上打开浏览器访问非系统页面。

违反上述规定可能影响生产处置有效性，并触发审计和追责。

## 6. 紧急情况

- 发现产线安全事故：立即按下急停按钮，确保人身安全优先。
- 系统显示大规模异常 PASS：立即通知质量负责人，在质量负责人确认前不得继续生产。
- 工控机严重故障：联系运维，记录最后一条检测刀具 ID 和时间。
