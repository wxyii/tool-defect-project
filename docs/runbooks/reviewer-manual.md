# 复核员手册

## 角色边界与高风险控制

- 所需权限：仅允许认领和提交分配的复核任务；不得审批数据集/模型、发布、回滚、提权或删除审计记录。
- 操作原因：PASS、FAIL、HOLD、推翻和标注修改都必须填写有效原因代码。
- 二次确认：盲审冲突、最终处置推翻和高风险批量操作由不同质量负责人确认。
- 审计事件：认领、查看敏感图像、提交、冲突、超时和权限拒绝全部记录。

证据不完整、图像不可判或独立复核冲突时保持 `HOLD`，不得猜测结论。

受众：人工复核员。权限：认领并提交授权范围内的复核。禁止：发布模型、修改其他人的记录。

## 1. 复核工作流

### 1.1 任务认领

1. 登录后进入复核任务池，系统默认按等待时间降序排列。
2. 点击"认领"获取下一个待复核任务。每次只能持有一个活跃复核。
3. 认领后任务进入"处理中"状态，其他复核员不可见。
4. 任务认领后 30 分钟内未提交将自动释放回队列。

### 1.2 复核流程

1. 在复核工作台查看检测图像及相关模型输出。
2. 判断工具是否存在缺陷：
   - 有缺陷：标注缺陷区域并选择缺陷原因代码。
   - 无缺陷：确认无缺陷，不需要标注。
   - 无法判断：升级至质量负责人。
3. 填写复核意见。
4. 提交复核结论。

### 1.3 盲审二审

- 质量负责人在指定任务类型中启用盲审二审模式。
- 盲审模式下同一任务由两位复核员独立复核，均不查看对方结果。
- 结论一致时自动采纳；不一致时升级至质量负责人裁决。
- 二审流程启用时，不要查看或讨论他人复核结果。

## 2. 图像工作台使用

### 2.1 基础操作

- 鼠标滚轮缩放图像。
- 按住并拖动平移图像。
- 双击图像区域恢复适合屏幕的视图。

### 2.2 叠加切换

- 工具栏提供叠加开关：原始图、热图、分割掩膜。
- 可同时开启多个叠加层，通过透明度滑条调整。
- 热图指示模型关注的区域，掩膜指示模型分割出的缺陷轮廓。

### 2.3 画笔与橡皮擦

- 画笔模式（`B`）：在图像上绘制缺陷区域。按住拖动连续绘制。
- 橡皮擦模式（`E`）：擦除已绘制的缺陷区域。
- 撤销（`Ctrl+Z` / `Cmd+Z`）：撤销上一次绘制或擦除操作。
- 重做（`Ctrl+Y` / `Cmd+Shift+Z`）：恢复撤销的操作。
- 画笔大小通过工具栏滑块或 `[` `]` 键调整。
- 自动闭合：绘制轮廓后双击自动闭合多边形。

### 2.4 极坐标联动（P2 功能）

- 展开图像在极坐标空间展示，便于观察环形刀具表面连续性缺陷。
- 直角坐标和极坐标视图联动滚动和平移。
- 在任一视图中的标注同步到另一视图。

## 3. 标注指南

### 3.1 什么构成缺陷

以下情况应标记为缺陷：
- 刀具表面可见的裂纹、崩刃、缺口或剥落。
- 涂层不均匀、脱落或变色超出公差。
- 刃口变形、卷边或磨损超出允收标准（参照质量规范）。
- 表面异物附着无法通过清洁去除。

以下情况不应标记为缺陷：
- 表面正常切削液残留（清洁后可确认）。
- 已知工艺特征（如打标字符、定位槽、冷却孔）。
- 图像噪点或光照不均匀产生的伪影（通过与周边区域对比确认）。

### 3.2 掩膜标记方法

1. 确认缺陷区域后，选择适合的画笔大小。
2. 沿缺陷轮廓精确绘制，避免过多包含正常区域。
3. 多个不连通的缺陷分别标记，不使用单一掩膜覆盖所有区域。
4. 掩膜绘制完成后再次切换叠加层检查覆盖是否准确。
5. 如有不确定的边缘区域，宁可略微扩大标注也不要遗漏。

### 3.3 注意事项

- 未经确认不要根据模型热图直接标注，应结合原始图像独立判断。
- 不要标注模型已正确识别但在人工判断中不构成缺陷的区域。
- 分辨率不足以判断的区域标注为"不确定"，在意见中说明。

## 4. 缺陷原因代码

| 代码 | 含义 | 使用场景 |
|------|------|----------|
| WEAR | 自然磨损 | 刀具达到使用寿命后的渐进退化 |
| CHIP | 崩刃 | 局部脆性断裂或缺损 |
| CRACK | 裂纹 | 可见线状或网状裂纹 |
| COAT | 涂层剥落 | 涂层局部脱落或起皮 |
| DEFORM | 变形 | 刃口塑性变形或卷边 |
| ADHESION | 粘屑 | 切削材料粘附在刀具表面 |
| BUE | 积屑瘤 | 刃口处堆积切削材料 |
| UNKNOWN | 未知 | 存在缺陷但无法归类 |

选择原则：
- 优先选择最接近根因的代码。
- 如多个原因共存，选择最主要的缺陷类型，在意见中备注次要缺陷。
- 不确定时使用 `UNKNOWN` 并在意见中描述观察到的情况。

## 5. 升级

以下情况应升级至质量负责人：
- 图像质量不足以做出可靠判断。
- 缺陷类型或严重程度超出标准规范。
- 疑似新型缺陷或系统性偏差。
- 与历史同类任务存在明显矛盾的结论。
- 盲审二审结论不一致。

升级操作：在复核意见中勾选"升级至质量负责人"并填写升级原因。

## 6. 常见错误

### 6.1 未正确标注直接提交

- 结论为不合格但未绘制任何掩膜。
- 原因：忘了标注或误点提交。
- 避免：提交前检查掩膜叠加视图，确认缺陷区域已覆盖。

### 6.2 原因代码选择错误

- 将崩刃标为磨损，或将粘屑标为涂层剥落。
- 原因：未仔细对比缺陷形态和代码定义。
- 避免：不确定时查阅原因代码表或使用 `UNKNOWN` 并在意见中描述。

### 6.3 批量快速复核

- 短时间内提交大量结论且意见为空，缺乏仔细审查。
- 避免：每件任务独立判断。系统记录复核时长，异常快速通过将触发审计。

### 6.4 忽略图像质量

- 在模糊、过曝或过暗图像上强行判断。
- 避免：图像质量不足以判断时应升级，不应猜测结论。

## 7. 效率与质量平衡

- 建议每件复核时间不少于 15 秒，复杂任务适当延长。
- 质量负责人定期抽检复核结论，抽检结果计入复核员质量评分。
- 抽检通过率持续低于 90% 的复核员需接受重新培训。
- 复核质量比速度优先。系统 SLA 监控的是整体时限，不应为赶时限牺牲判断质量。
