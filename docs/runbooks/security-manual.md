# 安全负责人操作手册

## 角色边界

安全负责人管理安全策略、证书吊销、机密轮换和安全事件响应；不得作质量裁决、登记或发布模型，也不得删除审计记录。

## 正常操作

1. 只读核对证书链、吊销列表、身份提供方、网络策略和安全告警。
2. 按批准工单执行演练证书吊销、机密轮换和应急账号确认。
3. 与管理员、运维和审计员分别核对执行、恢复和审计结果。

## 高风险控制

- 所需权限：限时安全管理权限，不含业务处置或模型发布权限。
- 操作原因：证书吊销、密钥轮换、紧急账号和策略变更必须记录原因。
- 二次确认：由不同的管理员或运维负责人确认目标和影响范围。
- 审计事件：请求、批准、执行、传播、恢复和凭据回收全程记录。

## 安全失败

身份、证书、确认人或审计写入未知时拒绝操作，受影响主体保持禁用或 `HOLD`，不得通过放宽认证恢复业务。
