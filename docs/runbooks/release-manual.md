# 发布负责人操作手册

## 角色边界

发布负责人执行已批准的影子、灰度、正式切换和回滚；不得兼任模型登记、质量批准或审计批准角色，不得发布未签名或未预热制品。

## 正常操作

1. 核对发布申请、当前模型、候选模型和上一稳定模型的不可变标识与 SHA-256。
2. 核对质量批准、回滚目标预热、监控窗口和停止条件。
3. 按批准流量逐级切换，每一步保留指标与审计证据。

## 高风险控制

- 所需权限：限时发布权限，不含模型登记和质量审批权限。
- 操作原因：正式切换、停止灰度和回滚均必须记录原因。
- 二次确认：由不同的质量负责人确认目标、范围和回滚条件。
- 审计事件：请求、批准、切换、停止、回滚和验证均形成追加写事件。

## 安全失败

任一签名、哈希、批准、预热、监控或回滚前置缺失时停止切换，新任务进入 `HOLD` 或继续使用已验证稳定版本，不得静默继续。
