# 审计员操作手册

## 角色边界

审计员只读核查业务、身份、模型、发布、恢复和应急操作证据；不得执行被审计操作、修改事实记录或替代业务批准人。

## 正常操作

1. 按事件编号核对主体、时间、原因、资源、前后状态、请求和追踪标识。
2. 核对职责分离、二次确认、证据 SHA-256 和追加写约束。
3. 对缺失、冲突或不可复算证据登记发现并要求进入 `HOLD`。

## 高风险控制

- 所需权限：只读审计查询与受控导出权限。
- 操作原因：导出和跨域查询必须绑定审计任务原因。
- 二次确认：包含个人或安全敏感信息的导出由安全负责人确认。
- 审计事件：审计查询和导出本身也必须被审计，且不能由审计员删除。

## 安全失败

审计链断裂、哈希冲突、时钟异常或角色不独立时结论为 `HOLD`/不通过，禁止用缺失字段的默认值补全事实。
