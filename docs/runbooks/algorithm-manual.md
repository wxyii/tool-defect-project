# 算法负责人操作手册

## 角色边界

算法负责人分析模型、数据和推理异常，可以提出候选模型与阈值建议；不得自行批准或发布生产模型，不得修改历史检测和处置事实。

## 正常操作

1. 只读核对模型版本、包 SHA-256、数据集版本、预处理版本和评估证据。
2. 对异常样本记录分析原因、复现步骤和影响范围。
3. 提交模型或阈值变更申请，由质量和发布角色独立审批。

## 高风险控制

- 所需权限：只读生产诊断和候选登记权限，不含生产发布权限。
- 操作原因：模型回滚、阈值变更和数据导出必须填写不可空原因。
- 二次确认：任何影响生产流量的建议由质量或发布负责人确认。
- 审计事件：查询、导出、候选登记和变更申请均记录主体、资源、原因与结果。

## 安全失败

模型身份、签名、哈希、输入输出模式或审批状态未知时停止操作并保持 `HOLD`，不得给出 `PASS` 或启用流量。
