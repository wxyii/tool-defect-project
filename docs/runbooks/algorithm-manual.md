# 外部模型来源包与验证证据手册

> 本文件沿用历史文件名。“算法负责人”是系统边界外的组织责任，不是第二版在线人员角色。在线人员角色只有生产员工和管理员。

## 1. 职责和边界

外部算法责任人可以使用经批准交接的样本导出包，在系统边界外完成整理、数据集划分、训练、实验跟踪和离线评估，并向管理员交付外部模型包和来源证据。

外部算法责任人不得：

- 获得在线业务数据库、消息队列、内部对象存储或生产运行时凭据。
- 在在线系统创建、冻结、批准或比较数据集版本。
- 在在线系统创建、调度或查询训练任务、进度、日志和检查点。
- 通过服务间回调登记训练状态或直接写模型版本。
- 直接上传到生产模型前缀、调用启用接口或修改生产别名。
- 修改历史检测、反馈、样本候选、导出和审计事实。

外部训练环境的中断、排队和失败不影响在线检测、复核、样本导出、模型验证和生产运行，也不产生在线服务告警。

## 2. 接收样本导出包

1. 由授权管理员创建导出并通过受控渠道交接。
2. 核对导出作业标识、模式版本、文件数量、清单哈希和包 SHA-256。
3. 核对逐项来源、系统结论、人工结论、管理员标记、质量结果、使用阶段和模型版本。
4. 对缺失对象、哈希冲突、标签争议和失败清单保持隔离，不把它们默认为可用样本。
5. 记录外部接收人、接收时间、包哈希和用途。

短时下载票据不得保存为长期凭据。外部环境只接收导出包，不直接读取在线原图桶或业务数据库。

## 3. 外部整理和训练

外部数据集、训练运行、进度、日志、检查点和实验记录由外部环境自行治理，不属于第二版在线契约。在线系统不调度、不轮询、不回调这些过程。

外部流程至少应保留：

- 所使用导出包的标识、模式版本和 SHA-256。
- 外部数据处理、划分和冲突处置说明。
- 代码版本、配置、环境、随机种子和制品哈希。
- 评估范围、指标分母、分层结果、已知限制和责任人。
- 许可证、第三方组件和供应链来源。

这些信息最终以来源说明或证据附件进入模型包，但不补造内部数据集版本或训练运行。

## 4. 外部模型包

### 4.1 必需内容

- 模型制品和逐文件 SHA-256。
- 包模式版本、模型名称和语义版本。
- 输入尺寸、通道、归一化、输出名称和类别映射。
- 框架、运行时和允许插件版本。
- 外部来源说明、许可证和责任人。
- 外部评估摘要、测试范围、指标分母和已知限制。
- 预期资源上限和目标硬件说明。

模型包不得包含明文密钥、长期票据、任意安装脚本、未声明可执行文件、绝对路径或指向外部任意网址的运行依赖。

### 4.2 交付

1. 生成不可变包并计算逐文件和整体 SHA-256。
2. 通过批准的文件交接渠道交给授权管理员。
3. 向管理员提供声明哈希、版本、来源说明和验证注意事项。
4. 管理员从 `/models` 创建上传会话，并用浏览器短期票据直接上传到隔离区。
5. 外部算法责任人不得持有上传会话凭据或绕过管理员代传到生产目录。

## 5. 隔离验证证据

管理员完成上传确认后，在线验证作业至少检查：

1. 路径穿越、符号链接、嵌套包、文件数和解压大小。
2. 文件清单、声明哈希和实际哈希。
3. 框架、插件、反序列化格式和许可证白名单。
4. 输入输出模式、类别映射和预处理兼容性。
5. 模型加载、预热、固定安全样例和资源上限。
6. 外部来源说明和评估证据完整性。

外部算法责任人可以解释失败原因并重新生成新版本包，但不能修改隔离区对象、覆盖原包或把失败状态改为通过。任何修复都必须形成新的不可变包、版本和哈希。

## 6. 启用建议

外部算法责任人可以提交技术建议，包括固定样例对比、关键缺陷类型、推理时延、资源使用、灰度范围和回滚条件。建议不等于在线批准。

只有已通过隔离验证的模型才能由管理员发起启用申请，并由不同管理员账号确认。加载、预热或原子切换失败时保持当前生产模型。外部算法责任人不得直接操作生产流量。

## 7. 安全失败

- 导出包或模型包身份、清单、哈希、来源权限未知：停止处理。
- 输入输出模式、类别映射、框架兼容性或许可证未知：不得建议启用。
- 固定样例或资源上限检查失败：重新生成模型包，不修改验证结论。
- 在线系统要求内部数据集版本、训练运行或训练服务可用：视为范围回归并报告。
- 外部训练失败：只在外部环境处理，不把在线检测置为 `PASS` 或虚假成功。

## 8. 审计交接清单

- 样本导出作业标识、清单哈希和包 SHA-256。
- 外部接收人、用途和处理边界。
- 模型包名称、版本、逐文件哈希和整体 SHA-256。
- 外部来源、评估摘要、许可证和已知限制。
- 管理员上传会话、隔离验证结果和拒绝原因引用。
- 启用建议、灰度范围和回滚条件。

交接记录只保存证据和引用，不包含在线凭据、短时票据或模型二进制。
