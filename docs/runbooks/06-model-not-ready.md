# 生产模型无就绪实例

严重级别：S1

## 影响确认

- 确认生产别名、目标不可变版本、就绪实例数、加载错误与信任根状态。
- 无就绪模型时不得使用未知或研究候选替代，任务进入 `HOLD`。

## 只读检查

- 查看模型清单、包摘要、签名、框架版本、流水线版本、资源配额与上一稳定版本预热状态。
- 核对已有任务绑定的模型版本，别名变化不得改变历史任务。

## 恢复步骤

1. 修复资源或重新加载同一已批准版本，完整执行摘要与签名验证。
2. 若版本本身失败，按批准流程切换到已预热的上一稳定不可变版本。
3. 恢复消费，优先处理仍绑定有效版本的积压任务。

## 升级路径

- 签名失败、信任根未知、没有批准回滚版本或资源持续崩溃时升级发布负责人、安全负责人和事件指挥。

## 恢复验证

- 就绪实例大于零、健康门禁通过、固定探针结果一致、积压下降且历史任务版本未改变。
- 模型可信状态不明确时继续 `HOLD`。

## 危险操作控制

- 所需权限：模型发布；操作原因：批准记录与版本标识；二次确认：质量和发布职责分离；审计事件：`model.alias.changed`。
- 禁止训练身份写生产别名或加载未签名模型包。
