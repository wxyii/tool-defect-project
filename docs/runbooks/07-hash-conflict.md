# 哈希冲突

严重级别：S1

## 影响确认

- 立即停止相关对象、模型、数据集或恢复点的后续消费，记录期望与实际摘要、来源和首次发现时间。
- 冲突不得通过重命名或覆盖消除，所有相关任务进入 `HOLD`。

## 只读检查

- 从独立副本随机重算 SHA-256，核对大小、媒体类型、不可变清单、上传确认和审计链。
- 检查是否为键碰撞、传输截断、错误版本或签名失败，不输出敏感内容。

## 恢复步骤

1. 隔离冲突制品和关联任务，保留两份证据。
2. 从已验证恢复点恢复到新不可变键，重新建立引用而不改写旧事实。
3. 对受影响范围执行全量引用闭包和摘要检查。

## 升级路径

- 模型包、原图或备份恢复点冲突立即升级安全、质量和事件指挥；范围未知按全局 S1 处理。

## 恢复验证

- 新制品摘要、签名和引用闭包全部通过，旧冲突证据仍可审计，相关任务没有错误 `PASS`。
- 原因或范围不明时继续 `HOLD`。

## 危险操作控制

- 所需权限：证据隔离与恢复；操作原因：冲突指纹和影响范围；二次确认：安全与质量负责人；审计事件：`integrity.conflict.resolved`。
- 禁止覆盖、删除或伪造冲突制品的原始记录。
