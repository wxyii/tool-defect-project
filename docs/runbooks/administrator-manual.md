# 管理员操作手册

## 角色边界

管理员维护用户、角色、证书绑定和紧急账号生命周期；不得执行质量裁决、模型批准、发布决定或删除审计记录。

## 正常操作

1. 根据已批准工单授予最小权限并设置有效期。
2. 定期复核离职、调岗、禁用账号和角色冲突。
3. 验证权限拒绝、证书吊销和紧急账号自动回收。

## 高风险控制

- 所需权限：身份与角色管理权限，不含业务处置和模型发布权限。
- 操作原因：提权、紧急账号、证书吊销和凭据轮换必须填写原因。
- 二次确认：安全负责人或运维负责人以不同账号确认高风险动作。
- 审计事件：申请人、执行人、确认人、前后权限、时限和结果完整记录。

## 安全失败

工单、确认人、有效期或审计写入失败时拒绝权限变更；身份提供方状态未知时不扩大权限，紧急账号保持禁用，业务状态保持 `HOLD`。
