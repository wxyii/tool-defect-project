# 前端功能规划

## 1. 文档职责

本文定义 Vue 前端的信息架构、页面、交互、角色可见性和实施优先级。业务状态、复核规则和权限判断分别由对应后端文档定义；前端只展示和提交，不自行判定合格或不合格。

## 2. 用户类型

| 用户 | 主要目标 |
|---|---|
| 现场操作员 | 查看设备、采集、上传和当前刀具处置 |
| 人工复核员 | 处理待复核任务并修订二值掩膜 |
| 质量负责人 | 处理升级任务、查看质量趋势和批准数据 |
| 算法工程师 | 查看模型错误样本、数据集和训练评估 |
| 模型发布负责人 | 审批灰度、生产发布和回滚 |
| 系统管理员 | 执行全部人员业务操作，并管理工位、设备、配置、用户和系统健康 |
| 审计员 | 只读查看处置、审批和安全审计 |

同一前端按权限动态构建菜单，但所有接口仍由后端再次鉴权。

## 3. 信息架构

```text
/workstation                 工位实时页
/dashboard                   系统总览
/detections                  检测记录
/detections/:id              检测详情
/reviews                     复核任务池
/reviews/:id                 复核工作台
/quality                     质量分析
/datasets                    数据集版本
/training-runs               训练运行
/models                      模型与部署
/devices                     设备与工位
/alerts                      告警与处置
/audit                       审计查询
/settings                    受控配置
```

路由存在不等于用户可见。权限不足时不渲染菜单，直接访问仍由路由守卫和后端共同拒绝。

## 4. 工位实时页

面向车间工控机，默认全屏或大屏模式。

### 4.1 顶部状态

- 工位、产线、班次和当前时间。
- 中心连接状态。
- 相机、PLC、采集代理状态。
- 本地待上传数量、最老任务年龄和磁盘使用率。
- 当前生效采集配方和检测流水线版本。

### 4.2 当前刀具

- 原图缩略图。
- 采集时间和 `capture_id` 简写。
- 当前阶段：采集中、上传中、检测中、待复核、已完成或异常。
- 最终生产处置：`PASS`、`FAIL`、`HOLD`。
- 算法结论、置信度和缺陷叠加图作为辅助信息。

颜色不能是唯一提示。必须同时显示中文文字、图标和可选声音。`HOLD` 使用明确的“暂停并等待处理”文案，不能显示为模糊的“未知”。

### 4.3 最近记录

显示本工位最近若干次采集、处置和耗时。点击进入详情需要相应权限。

### 4.4 离线表现

中心断开时：

- 明确显示“中心离线，采集客户端正在本地排队”。
- 展示最近一次成功同步时间和本地队列摘要。
- 禁止前端伪造最终处置。
- 浏览器页面不可用不影响后台采集服务。

## 5. 系统总览

按授权范围展示：

- 今日采集量、`PASS`、`FAIL`、`HOLD`。
- 待复核数量和最老等待时间。
- 在线工位和异常设备。
- 推理队列深度、处理时延和失败率。
- 当前生产模型及灰度状态。
- 数据质量和模型结论分布变化。

所有比率显示分母和时间范围。没有足够真值时，不能把算法 `UNQUALIFIED` 比率称为真实缺陷率。

## 6. 检测记录

### 6.1 筛选

- 时间范围。
- 产线、工位、设备和批次。
- 最终处置。
- 算法结论。
- 复核状态。
- 模型和流水线版本。
- 图片质量和错误码。

筛选条件同步到 URL，便于分享经过权限校验的查询，不在 URL 中放令牌或敏感信息。

### 6.2 列表

列包含采集时间、工位、缩略图、算法结论、最终处置、置信度、复核状态、模型版本和总耗时。大列表使用服务端游标分页，不把全量数据加载到浏览器。

### 6.3 详情

分为：

1. 原图与派生图查看器。
2. 算法结果和缺陷区域。
3. 执行尝试、预处理警告和耗时。
4. 最终处置及历史修订。
5. 复核记录。
6. 模型、配置和数据版本。
7. 审计时间线。

普通用户只看到脱敏错误摘要；详细堆栈不进入前端。

## 7. 图片查看器

必须支持：

- 原图、掩膜、轮廓、热图和叠加图独立开关。
- 缩放、平移、适应窗口和 100% 查看。
- 透明度调节。
- 原图与极坐标图联动定位。
- 原图和模型坐标系明确标识。
- 大图分级加载，先缩略图后全分辨率。
- 签名地址过期后自动重新申请，不把地址长期缓存。

默认先展示原图，再允许开启算法叠加。复核模式下不能只展示带提示的图。

## 8. 复核任务池

- 按优先级、等待时间和工位展示。
- 支持只看本人认领、待二审和升级任务。
- 显示租约剩余时间。
- 提供认领、释放和进入工作台操作。
- 任务数量实时更新，但状态以提交时后端校验为准。

批量通过只允许质量规则明确授权的随机抽检任务，强制复核和异常任务禁止批量操作。

## 9. 复核工作台

### 9.1 布局

- 左侧：原图和标注工具。
- 右侧：采集信息、算法证据、结论和原因。
- 底部：保存草稿、提交、释放和升级。

### 9.2 标注工具

- 画笔、橡皮、区域填充、撤销和重做。
- 掩膜显示和隐藏。
- 画笔像素大小随缩放调整。
- 提交前校验掩膜尺寸、值域和非空规则。
- 自动保存本地草稿，但草稿不等于已提交业务记录。

### 9.3 并发

页面保存进入时的 `record_version`。提交冲突时显示最新任务状态和差异，用户选择刷新；不能静默覆盖。

### 9.4 防偏差

- 默认关闭模型叠加。
- 双人盲审隐藏前一复核结论。
- 先要求选择生产处置，再允许查看某些解释性摘要的具体策略可配置并通过可用性测试。

## 10. 质量分析

看板包含：

- 自动 `PASS` 抽检不合格率。
- 模型被推翻率。
- 漏检、误报和掩膜修订原因。
- 按模型、工位、班次、批次和缺陷尺寸分层。
- 图片质量问题趋势。
- 双人复核一致率。

图表必须显示样本量、时间窗口、筛选条件和是否基于全量真值。小样本不显示误导性的高精度百分比。

## 11. 数据集与训练

### 11.1 数据集

- 数据集版本、父版本、样本数、划分和哈希。
- 重复、冲突、泄漏和来源审计报告。
- 版本间新增、删除和标签变化。
- 批准或拒绝候选版本。

前端不能直接编辑已发布清单；修改会创建新版本。

### 11.2 训练运行

- 配置、代码提交、数据集、环境和随机种子。
- 运行阶段、日志摘要和指标曲线。
- 最佳检查点、失败原因和资源使用。
- 与基线的固定测试比较。

长任务通过服务器发送事件更新，不持续高频轮询。

### 11.3 模型与部署

- 模型版本、制品哈希、输入输出和评估报告。
- `DRAFT` 到 `PRODUCTION` 的状态。
- 影子、灰度和生产流量范围。
- 审批链、观察窗口和回滚目标。

发布按钮只创建申请，不允许算法工程师单击后直接替换生产模型。

## 12. 设备与配置

设备页面显示：

- 工位拓扑、设备型号、序列号和代理版本。
- 心跳、相机、PLC、本地队列、磁盘和时钟。
- 当前配方和配置版本。
- 最近错误与维护记录。

配置编辑采用“草稿、校验、审批、生效、回滚”流程。涉及触发、相机曝光、自动放行和保留期的变更必须展示影响范围。

## 13. 告警与审计

告警页支持：

- 当前、已确认、已恢复和已关闭。
- 按服务、工位、严重度和错误码筛选。
- 记录确认人、处置说明和关联运行手册。

审计页只读，支持按人员、动作、资源和时间检索。前端不允许删除审计记录。

## 14. 权限可见性

| 功能 | 操作员 | 复核员 | 质量负责人 | 算法工程师 | 发布负责人 | 管理员 | 审计员 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 工位实时查看 | 是 | 是 | 是 | 只读 | 只读 | 是 | 只读 |
| 提交复核 | 否 | 是 | 是 | 否 | 否 | 否 | 否 |
| 质量裁决 | 否 | 否 | 是 | 否 | 否 | 否 | 否 |
| 创建训练 | 否 | 否 | 可批准数据 | 是 | 否 | 否 | 否 |
| 发布审批 | 否 | 否 | 质量审批 | 否 | 技术审批 | 运维执行 | 只读 |
| 用户与设备管理 | 否 | 否 | 否 | 否 | 否 | 是 | 只读 |

此表只描述页面入口，最终权限以 [12-安全权限与角色](12-安全权限与角色.md) 为准。

## 15. 前端工程要求

- Vue 3、TypeScript 和组合式接口。
- 从 OpenAPI 生成请求类型和基础客户端。
- 统一处理令牌刷新、请求标识、错误码和权限。
- 业务状态字典由共享契约生成，不手写多份。
- 组件分为业务组件、图片标注组件和通用组件。
- 不在浏览器存储长期令牌、对象存储凭据或完整原图。
- 所有危险操作显示目标、影响范围并要求原因。
- 支持 1920 x 1080 工控机屏幕，并验证常见缩放比例。

## 16. 实施优先级

### P0：现场闭环

1. 登录和权限。
2. 工位实时页。
3. 检测记录和详情。
4. 复核任务池和基础复核。
5. 设备与本地队列状态。
6. 关键告警。

### P1：质量和模型闭环

1. 高级掩膜编辑。
2. 双人复核。
3. 质量看板。
4. 数据集、训练和模型版本查看。
5. 灰度与回滚审批。

### P2：效率优化

1. 极坐标联动查看。
2. 批量导出和报告。
3. 可配置看板。
4. 跨批次错误分析。
5. 移动端只读告警。

## 17. 前端验收

- 状态与后端一致，刷新或断线恢复后不倒退。
- 未授权路由、按钮和接口均不可用。
- 大图查看不阻塞整个页面。
- 签名地址过期可恢复。
- 复核并发冲突不会丢失他人提交。
- `PASS`、`FAIL`、`HOLD` 在色盲和无声音条件下仍可区分。
- 浏览器关闭不影响采集客户端继续工作。
