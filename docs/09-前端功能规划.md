# 前端功能规划

## 1. 文档职责

本文定义 Vue 前端的目标信息架构、页面、交互、角色可见性、退役范围和实施优先级。业务状态、处置规则和权限判断由后端与共享契约定义；前端只展示服务端事实并提交用户操作，不自行聚合最终处置。

目标人员业务角色只有“生产员工”和“管理员”。设备身份、采集代理和服务身份不属于前端人员角色。

## 2. 用户类型

| 用户 | 主要目标 |
|---|---|
| 生产员工 | 发起浏览器手工批量检测、查看本人批次和授权产线记录、对逐图结果提交三按钮反馈 |
| 管理员 | 执行生产员工能力，并管理用户、全部授权检测记录、管理员反馈、待整理样本、样本导出、模型直接上传、启用和回滚 |

管理员拥有较大业务范围，但高风险操作仍受原子权限、数据范围、资源状态和不同账号确认约束。前端隐藏入口不能代替后端鉴权。

旧操作员、复核员、质量负责人、算法工程师、模型发布负责人、系统管理员和审计员不得继续作为第二版页面角色选项或会话角色。迁移期旧授权只能在后端作为只读映射依据，未经确认不得自动提升为管理员。

## 3. 目标信息架构

```text
/                                  角色首页
/manual-detection                  手工批量检测
/detection-batches                 批次历史
/detection-batches/:id             批次结果与逐图反馈
/workstation                       产线实时页
/detections                        全部授权检测记录
/detections/:id                    图片项详情
/admin-feedback                    管理员反馈
/quality                           质量分析
/samples                           待整理样本与导出
/models                            模型直接上传、验证、启用与回滚
/users                             用户管理
/devices                           设备与工位
/alerts                            告警与处置
/audit                             审计查询
/settings                          受控配置
```

生产员工默认进入角色首页，只看到手工检测、本人批次、授权产线记录和个人设置。管理员默认进入管理首页，并按原子权限显示管理入口。

以下旧路由必须退役且不得出现在路由表、菜单、面包屑、站内搜索、快捷入口或权限声明中：

```text
/datasets
/datasets/:id
/training-runs
/training-runs/:id
```

兼容期可以为旧书签显示一次性退役说明，随后返回明确的 `404` 或 `410`；不得把旧路由自动重定向到 `/samples` 或 `/models`，因为样本导出不等于数据集版本，模型验证也不等于训练运行。

## 4. 角色首页

### 4.1 生产员工首页

- “开始手工检测”主入口。
- 本人最近批次、进行中批次和待反馈数量。
- 授权产线的最近处置与异常提示。
- 当前账号、密码修改和退出入口。

### 4.2 管理员首页

- 全部授权范围内的批次、异常、待管理员反馈和待整理样本摘要。
- 样本导出作业状态、模型验证状态和待确认启用申请。
- 设备、队列、对象存储和推理服务健康摘要。
- 用户、审计和受控配置入口。

首页不得展示数据集版本、训练运行、训练队列、训练资源或训练日志卡片。

## 5. 手工批量检测

### 5.1 选择和预览

- 支持点击选择和拖拽多张图片。
- 明确显示允许格式、单图大小、批次最大图片数和总大小。
- 每张图片形成一个独立图片项，仅有一个原图；页面不得出现多视角、主图、辅图或 `image_role` 语义。
- 使用文件名和缩略图帮助用户核对，但文件名不作为业务标识。
- 支持提交前删除、清空和重新选择，禁止浏览器自行改写图片内容。
- 显示本次使用阶段；提交后该值锁定。

### 5.2 上传和提交

页面采用“创建空批次—逐图取得上传票据—直接上传对象存储—逐图确认—一次提交批次”的交互。必须展示每张图片和整个批次的上传状态、可重试失败原因以及最终提交结果。

浏览器只使用短期、单对象、范围受限的上传授权。业务请求不得内嵌 Base64 图片，不得保存对象存储长期凭据。批次提交按钮是唯一业务提交动作；图片质量和推理步骤不呈现为要求用户逐步确认的向导。

### 5.3 处理和结果

- 提交后自动进入批次结果页，通过服务端推送或受控轮询刷新。
- 展示总数、完成数、疑似缺陷、未发现明显缺陷、不确定、图片质量异常和技术失败数量。
- 图片质量异常、不确定、疑似缺陷优先展示，正常图片默认折叠或使用小缩略图。
- 每个图片项展示原图、结果图、质量摘要、系统结论、使用阶段、检测时间和实际模型版本。
- 处理状态、聚合计数和最终处置全部来自后端；浏览器不得自行推断。

## 6. 批次历史和逐图反馈

### 6.1 批次列表

- 生产员工只能查看本人创建的手工批次和明确授权的产线记录。
- 管理员可以在授权范围内查看全部手工和产线批次。
- 支持时间、来源、创建人、批次状态、结果和使用阶段筛选。
- 列表展示批次编号、检测时间、图片总数、结果计数、操作人员、来源和聚合状态。
- 使用服务端游标分页，不把全量记录加载到浏览器。

### 6.2 批次与图片项详情

批次详情展示稳定聚合计数、状态版本和图片项列表。图片项详情展示原图、派生图、逐图质量检查、系统结论、人工反馈和历史修订。管理员额外看到模型版本、流水线版本、执行尝试、耗时和脱敏错误历史。

历史记录绑定检测时的模型和规则版本。当前模型切换不得改变旧页面显示，也不得用当前版本替换未知历史字段。

### 6.3 三按钮反馈

每个图片结果提供：

- “确认存在缺陷”。
- “确认无缺陷”。
- “无法判断”。

单次点击立即提交该图片项并显示保存状态，不提供“提交全部”。重复提交使用幂等键；修改已保存结论时创建修订并展示历史，不静默覆盖。选择“无法判断”后必须显示 `HOLD` 或等待后端处置的明确状态。

正常结果允许主动反馈但不强制逐张确认；疑似缺陷、质量边界和不确定结果突出显示按钮。

## 7. 产线实时页

面向车间工控机，可使用全屏或大屏布局。

### 7.1 顶部状态

- 工位、产线、班次和当前时间。
- 中心、相机、PLC 和采集代理状态。
- 本地待上传数量、最老任务年龄和磁盘使用率。
- 当前采集配方和检测流水线版本。

### 7.2 当前图片项

- 单张原图缩略图，不使用多视角采集语义。
- 采集时间、批次和图片项标识简写。
- 当前阶段和最终生产处置 `PASS`、`FAIL`、`HOLD`。
- 算法结论、置信度和缺陷叠加图只作为辅助证据。

颜色不能是唯一提示，必须同时显示中文文字和图标。`HOLD` 使用“暂停并等待处理”等明确文案，不能显示为模糊的“未知”。

### 7.3 离线表现

中心断开时显示最近成功同步时间、本地队列摘要和明确离线提示。浏览器不可用不影响后台采集服务，前端不得伪造最终处置。

## 8. 检测记录和图片查看器

### 8.1 检测记录

支持按时间、来源、产线、工位、设备、批次、创建人、最终处置、算法结论、人工结论、模型版本、使用阶段、图片质量和错误码筛选。筛选条件可以写入 URL，但令牌、对象票据和敏感信息不得进入 URL。

列表展示检测时间、来源、工位或创建人、缩略图、系统结论、最终处置、人工结论、模型版本和耗时。普通用户只看到脱敏错误摘要，详细堆栈不进入前端。

### 8.2 图片查看器

- 原图、掩膜、轮廓、热图和叠加图独立开关。
- 缩放、平移、适应窗口和 100% 查看。
- 透明度调节和坐标系标识。
- 大图先缩略图后全分辨率加载。
- 短时签名地址过期后重新申请，不长期缓存。

默认先显示原图，再允许开启算法叠加。任何管理员判断页面不得只显示带算法提示的图。

## 9. 管理员反馈

管理员可以按系统与人工不一致、无法判断、图片质量异常、定位争议、来源、时间和模型版本筛选图片项，并标记：

- 正确检出。
- 误报。
- 漏检。
- 定位不准。
- 图片不可用。
- 暂无法确认。

反馈必须即时创建不可变记录，修订时显示被替代版本。管理员可以基于指定反馈版本加入待整理样本库；页面不得用覆盖系统结论或生产员工反馈的方式“纠正”历史。

## 10. 质量分析

看板可以展示：

- 自动 `PASS` 抽检不合格率。
- 系统结论被推翻率。
- 漏检、误报、定位修订和图片不可用原因。
- 按模型、来源、工位、班次、批次、使用阶段和缺陷尺寸分层。
- 图片质量问题趋势和人工反馈一致性。

所有比率必须显示分母、时间窗口、筛选条件和真值覆盖范围。质量页面不得显示训练指标曲线、训练资源、训练进度，也不得成为已取消训练功能的替代入口。

## 11. 待整理样本与导出

`/samples` 是管理员页面，包含：

### 11.1 候选列表

- 按管理员标记、候选决定、来源、模型版本、使用阶段和时间筛选。
- 展示原图和结果图摘要、系统结论、生产员工结论、管理员标记及修订链。
- 支持纳入、排除和修订；批量操作必须显示数量、范围和影响。
- 同一图片项与同一反馈版本重复加入时展示已有候选，不创建重复项。

### 11.2 导出作业

- 从选定候选创建异步导出并显示筛选快照。
- 展示排队、执行中、部分失败、成功、失败和过期状态。
- 展示包内对象数、清单哈希、包哈希和逐项失败清单。
- 成功后按权限申请短时下载票据；大批量导出需要不同管理员确认。
- 导出不从候选库删除记录，也不创建数据集版本或训练任务。

页面不得使用“创建数据集”“冻结”“批准版本”“版本差异”或“开始训练”等按钮和文案。

## 12. 模型直接上传与部署

`/models` 面向管理员，按“上传会话、验证状态、模型版本、启用历史”组织，不出现训练运行。

### 12.1 直接上传

- 选择模型包并填写名称、版本、说明、外部来源、预期输入输出和声明 SHA-256。
- 创建会话后使用短期票据直接上传到隔离对象前缀。
- 展示文件大小、上传进度、可重试失败和会话到期时间。
- 上传完成后由服务端确认对象和哈希；页面不能把“上传完成”显示为“验证通过”。

### 12.2 隔离验证

展示包结构、安全扫描、哈希、输入输出、加载、预热、固定样例和资源限制检查。失败原因必须可操作且脱敏；验证失败包保持隔离，页面不得提供绕过验证的启用入口。

模型来源显示为经审计的外部说明和附件，不要求内部数据集版本或训练运行。页面不显示训练进度、日志、检查点、随机种子或调度资源。

### 12.3 启用和回滚

- 只允许针对验证通过的不可变模型版本发起启用申请。
- 明确显示当前生产版本、目标版本、灰度范围、观察窗口和已验证回滚目标。
- 申请人与确认人必须是不同管理员账号；前端提示该约束，后端强制执行。
- 切换失败时显示当前生产模型未变化，不允许乐观地更新页面别名。
- 回滚前展示重新加载和预热结果，历史检测继续显示实际执行版本。

## 13. 用户、设备、告警和审计

### 13.1 用户管理

管理员可以创建、编辑、启停、重置密码并指定“生产员工”或“管理员”。角色选择器不得出现旧细分角色，也不得出现数据集或训练相关权限。管理员账号变更必须展示影响并进入审计链。

### 13.2 设备与配置

展示工位拓扑、设备型号、序列号、代理版本、心跳、相机、PLC、本地队列、磁盘、时钟、当前配方和最近错误。配置编辑采用草稿、校验、确认、生效和回滚流程。

### 13.3 告警与审计

告警支持当前、已确认、已恢复和已关闭状态，按服务、工位、严重度和错误码筛选。审计页只读，支持按人员、动作、资源和时间查询，不允许页面删除审计记录。

告警和审计导航不得出现内部训练服务、数据集版本或训练运行资源。

## 14. 权限可见性

| 功能 | 生产员工 | 管理员 |
|---|---:|---:|
| 登录、退出、修改本人密码 | 允许 | 允许 |
| 创建手工批次和上传图片 | 允许 | 允许 |
| 查看本人手工批次 | 允许 | 允许 |
| 查看授权产线记录 | 按数据范围 | 按数据范围 |
| 提交三按钮反馈 | 按本人或授权范围 | 允许 |
| 查看全部人员批次 | 禁止 | 按数据范围允许 |
| 提交管理员反馈 | 禁止 | 允许 |
| 管理待整理样本和导出 | 禁止 | 允许，受确认和审计约束 |
| 直接上传和验证模型 | 禁止 | 允许 |
| 申请和确认启用或回滚 | 禁止 | 允许，但禁止同一账号自批 |
| 管理用户、设备和配置 | 禁止 | 按原子权限允许 |
| 查看审计 | 禁止 | 按原子权限允许 |
| 管理数据集版本或训练运行 | 不存在 | 不存在 |

此表只描述页面入口和交互范围，最终授权以共享契约和安全文档为准。任何直接访问仍由路由守卫和后端共同拒绝。

## 15. 前端工程要求

- 使用 Vue 3、TypeScript 和组合式接口。
- 从共享契约生成业务状态、请求类型和基础客户端，禁止手写网络类型。
- 统一处理令牌刷新、请求标识、幂等键、错误码、并发版本和权限拒绝。
- 不在浏览器存储长期令牌、对象存储凭据、完整原图或模型包。
- 图片和模型二进制通过短期票据直传对象存储，不进入业务 JSON。
- 大列表使用服务端游标分页；大图分级加载。
- 所有危险操作展示目标、数量、影响范围、回滚目标并要求原因。
- 支持 1920 x 1080 工控机屏幕、常见缩放比例、键盘操作和非颜色唯一提示。
- 前端不得实现最终处置、样本可用性、模型验证通过或生产启用规则。

## 16. 实施优先级

### P0：检测和反馈闭环

1. 两角色登录、角色首页和路由守卫。
2. 浏览器手工批量选择、预览、直传、提交和自动结果。
3. 批次历史、批次详情、图片项详情和三按钮反馈。
4. 产线实时页、检测记录和关键告警。
5. 管理员反馈、待整理样本基础列表和不可变审计。

### P1：导出和模型闭环

1. 候选纳入、排除、修订和批量选择。
2. 样本导出状态、失败清单和短时下载。
3. 模型直接上传、隔离验证证据和版本列表。
4. 不同管理员确认、影子或灰度、生产启用和回滚。
5. 用户、设备、质量和审计管理页面。

### P2：效率和可用性

1. 图片查看器联动和大图性能优化。
2. 可配置质量看板和跨批次分析。
3. 导出及模型操作的批量审计报告。
4. 移动端只读告警。

数据集和内部训练页面不属于任何阶段，不得以“后续功能”保留空菜单、占位路由或隐藏权限。

## 17. 旧页面和权限退役

1. 删除 `/datasets`、`/training-runs` 及详情路由和懒加载模块。
2. 删除主菜单、面包屑、快捷入口、站内搜索和通知中的对应链接。
3. 删除数据集创建、冻结、批准、差异和训练创建、调度、进度、日志组件。
4. 删除前端权限常量、角色矩阵和会话解析中的数据集版本与训练运行能力。
5. 删除第二版客户端对数据集和训练写接口或事件的生成引用。
6. 对旧书签显示退役说明或明确不存在，不重定向到语义不同的新页面。
7. 在端到端测试中断言取消路由不可达、取消菜单不存在、两类角色都没有相关权限。

退役只删除在线功能，不删除历史研究文件或审计事实。确需查看旧记录时，应通过受控只读迁移查询或离线归档完成，不恢复人员页面。

## 18. 前端验收
