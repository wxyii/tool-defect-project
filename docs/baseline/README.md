# P0 基线证据

- `P0-01-baseline-report.md`：人类可读资产、环境和测试冻结报告。
- `failure-register.json`：机器可读失败清单及安全行为。
- `tests/fixtures/baseline/baseline-lock.json`：不可变资产锁。
- `tests/fixtures/baseline/test-baseline.json`：P0 开始时测试结果。
- `R0-v1-runtime-inventory.json`：R0 第一版消费者、采集代理、角色用户、活动部署和历史多视角基线；无法由源码证明的运行数据明确为 `HOLD`。
- `R0-cancellation-inventory.json`：R0 取消页面、权限、接口、在线数据集/训练依赖和模型硬依赖的机器可读冻结清单。

本目录不包含图片、模型权重、大数组或运行输出。
