## 声明

项目所有者确认：仓库中的第一版实现从未实际部署或投入业务使用。第一版只有源码、冻结契约、测试、示例、迁移脚本和开发部署定义，不存在生产或现场运行实例、真实第一版业务用户、运行调用、历史第一版业务记录或历史多视角记录。

## R0 基线解释

1. `contracts/consumers/v1-consumers.json` 中的四类消费者是源码消费者清单，不代表曾存在运行消费者。
2. 第一版最后调用状态为 `NEVER_CALLED`；因从未部署，运行遥测来源和连续零调用观察窗口为不适用，而不是缺失。
3. 第一版现场采集代理、活动部署和真实用户数量均为零。
4. 第一版历史多视角业务记录数量为零；第一版模式和代码仍作为冻结兼容依据保留。
5. 取消清单仍必须执行源码迁移与清理任务，不能因为未使用而把旧页面、权限、接口或在线训练依赖带入第二版。

## 后果

- `R0-05` 的运行态冻结以“从未部署、数量为零、不适用运行遥测”闭合。
- `R0-06` 的取消范围按源码清单继续追踪，零调用条件直接满足。
- `RG0` 可以解除 `HOLD`，允许进入 R1 的契约阶段。
- 若后续发现任何第一版实际部署、调用或业务数据证据，本声明立即失效，`RG0` 重新进入 `HOLD`，并补做消费者遥测、历史数据盘点和迁移评估。
