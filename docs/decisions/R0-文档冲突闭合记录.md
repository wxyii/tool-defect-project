## 必须关闭的五项冲突

| 冲突 | 决策 |
|---|---|
| 删除多视角是否删除历史证据 | 否；只删除第二版新写和运行语义，历史只读保留，见 `ADR-0005` |
| 两个角色是否包含设备和服务身份 | 否；只收敛人员业务角色，见 `ADR-0006` |
| 直接上传是否上传后直接加载 | 否；浏览器直传隔离区并完成受限验证，见 `ADR-0007` |
| 一个启用模型的范围 | 每组织一个生产默认活动模型；影子、测试和验证不算生产启用，见 `ADR-0007` |
| 样本导出与模型上传是否经内部训练串联 | 否；二者是独立入口，见 `ADR-0003` |
