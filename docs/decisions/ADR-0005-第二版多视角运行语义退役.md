# ADR-0005：第二版多视角运行语义退役

- 状态：已接受
- 日期：2026-08-03
- 决策版本：`1.0.0`
- 需求基线：`DOC-16 1.1.1`
- 影响契约：第二版目标契约 `2.0.0`
- 影响阶段：`R0`、`R1`、`R2`、`R4`、`R9`

## 背景

第一版存在多视角、主视角和图片角色语义。目标流程以单张刀片原图为最小检测项，但历史多视角记录仍是检测、复核和审计证据。

## 决策

第二版新契约、新写入和运行路径全部采用“一图片项一原图”，不得包含多视角组装、主视角选择或 `image_role` 分支。第一版历史证据只读保留；无法无歧义迁移的记录进入旧版只读集合或 `HOLD`，禁止猜测主图、丢弃图片或自动重跑。

运行代码只能在第一版消费者归零、历史查询验证和批准回滚窗口结束后删除。第一版冻结契约和负向测试可继续出现旧术语，不计为第二版语义回流。

## 替代方案

1. 自动选择第一张或最高分图片作为主图：拒绝，因为会伪造历史语义。
2. 迁移时只保留一张图：拒绝，因为会删除审计证据。
3. 第二版继续保留可选多视角字段：拒绝，因为消费者会继续依赖旧分支。

## 后果

- 第二版推理任务只携带一个图片项和一个原图引用。
- 历史查询需要区分旧版只读证据和第二版可执行事实。
- 源码扫描必须允许冻结历史范围，但拒绝第二版契约与消费者中的旧语义。

## 回滚条件

第二版放量失败时只能回到仍开启且已验证的第一版适配路径；不得临时向第二版重新加入多视角字段。历史映射不确定、消费者遥测缺失或查询证据不完整时停止退役并进入 `HOLD`。
