# ADR-0001：前端构建使用 Node 20

- 状态：已确认
- 日期：2026-07-29
- 决策人：项目负责人
- 影响范围：`apps/web-console/`、持续集成前端任务、开发环境说明

## 背景

设计基线原建议使用 Node 24。项目负责人已明确允许将项目的 Node 要求降级为 Node 20，以兼容现有开发环境。

## 决策

- 前端构建运行时锁定为 Node 20，当前复现版本为 `20.13.1`。
- `package.json` 接受 `>=20.0.0 <21`。
- Vite 锁定在支持 Node 20.13 的 6.x 系列，相关插件与测试工具使用兼容版本。
- pnpm 锁定为支持 Node 20 的 10.x 系列，当前版本为 `10.34.5`。
- 依赖仍通过 `pnpm-lock.yaml` 精确锁定。

## 安全与兼容约束

- 不放宽到 Node 18 或更早版本。
- 升级 Vite 主版本前必须重新核对 Node 引擎约束并通过类型检查、单元测试和生产构建。
- 持续集成与本地构建必须运行相同的三项前端门禁。
