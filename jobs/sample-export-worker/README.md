# R7 样本导出 worker

worker 只处理管理员已经纳入导出的候选快照。它读取登记的原图和结果 JSON，逐对象核对媒体类型、大小和 SHA-256，再生成确定性的 ZIP 与 `manifest.json`。

导出包包含原图、允许的结果 JSON、系统结论/置信度/缺陷区域摘要、员工与管理员反馈、检测时间、使用阶段、来源和模型/流水线/规则版本。缺少版本证据、对象缺失、哈希冲突或写入依赖故障不会生成 `PASS`：候选数据错误进入逐项 `FAILED`，对象存储故障抛出可重试错误并由调度层保持 `HOLD`。

包和清单只写入 `sample-exports/` 前缀；worker 不创建数据集版本、训练运行、训练事件或内部训练调用。外部交接由管理员在业务系统中手工记录回执，不配置外部回调、轮询、订阅或凭据。
