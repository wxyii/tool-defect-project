# 契约示例

- 根目录和 `events/` 为必须通过的合法示例。
- `state-transitions-v1.json` 同时记录合法与明确禁止的转换。
- `invalid/cases-v1.json` 通过基准样例和 JSON Pointer 变更定义必须失败的负向向量，覆盖非法枚举、概率、空版本、缺失掩膜引用、本地绝对路径、事件二进制、任意网址、缺哈希、缺版本、未知字段和错误状态转换。
- `http/` 保存每个写接口的成功、重复、冲突、无权和校验失败示例。
- `events/events-v2.json` 为第二版全部事件提供合法载荷和未知字段反例。
- `state-transitions-v2.json` 覆盖批次、图片项、导出和模型上传的合法/非法转换。
- `http/write-examples-v2.json` 覆盖每个第二版写接口的成功状态，以及共享的重复、冲突、未授权、校验失败、非法状态和退役 `410` 语义。
